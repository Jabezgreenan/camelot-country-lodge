# Camelot Country Lodge

A responsive multi-page website built for **Camelot Country Lodge**, designed to provide visitors with an easy way to explore the lodge, view accommodation and facilities, browse photos, learn more about the property, and submit booking or contact enquiries.

## 🌐 Live Website

**[View the live website](https://camelot-country-lodge.vercel.app/)**

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Multi-page website structure
* Homepage with lodge information and featured content
* Accommodation/rooms page
* Facilities page
* Photo gallery
* About page
* Contact page
* Booking enquiry page
* Interactive navigation
* Contact and booking enquiry functionality
* Modern UI designed around a hospitality/guesthouse experience

## 📄 Pages

## 🚀 Running Locally

1. Clone the repository:

```bash
git clone https://github.com/Jabezgreenan/camelot-country-lodge.git
```

2. Open the project in VS Code.

3. Run the website using **Live Server** or another local static web server.

4. Open the local development URL in your browser.

Tailwind CSS is loaded through the CDN, so an internet connection is required for the Tailwind styles to load.
